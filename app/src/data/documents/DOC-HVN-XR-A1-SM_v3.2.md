# HeliosXR-A1 Service Manual (Fictional) v3.2

ハッカソン用架空文書。

## SEC-GEN-SAFE 安全上の基本（外観確認・電源表示）

- 作業前に権限と施設手順を確認する
- 外観損傷、異臭、異常音があれば作業を中断しエスカレーション
- AI支援は判断材料の整理に限り、作業承認は人間が行う

## SEC-GEN-READY Generator Ready 条件

Ready に必要な条件（架空の要約）:

- 重大エラーがクリアされていること
- インターロックが正常表示であること
- 冷却／電源表示が許容範囲であること

測定値が欠ける場合は Ready 不可の原因を断定しない。
